Lightweight / edge workloads

  • ▸Automatic GPU failover — Jellyfin moves NVENC (egbp-pc) ⇄ QSV (egbp-nuc) within ~1–2.5 min of a real node outage, and self-corrects the hardware-acceleration config on every boot regardless of which node it lands on.
  • ▸Longhorn distributed block storage plus one purpose-built NFS server for large media files — migrated off Longhorn's RWX mode after it proved unreliable under sustained read load.
  • ▸Every app is a local Helm chart in one git repo, synced by ArgoCD — direct kubectl/Helm changes are treated as drift to be formalized, not the steady state.

Platform

GitOps One Application per chart in ArgoCD, automated sync by default. A couple of apps deliberately run with self-heal off, where a controller mutates live replicas outside of git.
Secrets SOPS-encrypted at rest in git, decrypted in-cluster. Migrated across 10 apps in one pass, including a full history scrub for anything leaked before that.
Storage Longhorn for replicated block storage; a dedicated NFS server for the media library and Longhorn's own backup target.
Observability Prometheus + Grafana for metrics, Loki + Promtail for logs, Uptime Kuma for external checks.
